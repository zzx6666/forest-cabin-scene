# 林间 · 四季

一个使用 Three.js 程序化生成的 3D 童话森林木屋网页场景。场景不依赖外部模型、贴图或音频文件，可直接在浏览器中运行。

## 场景内容

- **春 · 花醒**：彩色花带、分区飞舞的蝴蝶、草丛间跳跃的兔子与缓慢巡游的小鹿。
- **夏 · 蛙鸣**：睡莲池、水里与岸上的青蛙、萤火虫、向日葵、门廊彩旗、遮阳伞与夏日野餐庭院。
- **秋 · 金林**：门前大型观赏红枫、分层树冠、银杏、南瓜、圆形草捆、落叶小径与持续旋转飘落的树叶。
- **冬 · 温泉**：积雪屋顶、六角形落雪、散乱庭院脚印、多个大小雪人、屋檐冰凌与冒白雾的温泉。
- **真实水面**：池塘实时反射天空与林木，叠加多频涟漪、深浅水色与四季漂浮物。
- **林地过渡**：草皮、蕨类、灌木、苔藓、野花、石块与落叶覆盖木屋到林线之间。
- **四季农田**：右前院独立围栏农田，春季黑土和种子、夏季青苗、秋季金黄作物、冬季积雪田埂。
- **室内场景**：扩建后的完整木屋内部，包含石砌壁炉、阁楼床、圆窗坐榻、厨房台面、餐桌、书柜、扶手椅、玩具箱与动态炉火。
- **四季室内陈设**：墙面主色、窗幔、地毯、座椅和床品随季节变化，并加入花环、绿藤、萤火罐、南瓜、落叶、窗外雪景、圣诞袜和礼物。
- 室外支持 360° 环绕观察，室内支持独立近距离环绕。
- 默认从春季开始自动巡展，每季 30 秒；无主动拖拽时镜头缓慢环视。
- 冬季展示结束后停止自动巡展，不回到春季循环。
- 底部时间条实时显示当前季节已播放时间和 30 秒总进度。
- 环境音乐由 Web Audio 实时合成，包含背景和弦、四季风声、鸟鸣、蝉鸣、虫鸣、蛙声与柴火声；首次合成优先放入 Worker，失败时自动分片降级。
- 背景音乐默认尝试自动播放；受浏览器策略限制时，首次点击或拖动会自动开启。

## 本地运行

```powershell
npm install
npm run dev
```

浏览器打开终端输出的本地地址，默认是 `http://localhost:5173/`。

自动化测试与生产构建：

```powershell
npm test
npm run build
npm run preview
```

性能或交互调试可使用查询参数：`?quality=high|balanced|mobile|low` 固定画质，`?debug=1` 暴露只读运行时快照与调试采样。

## 操作方式

- 暂停巡展：冻结当前季进度并进入室外自由观赏；继续巡展时镜头会平滑回到中心构图
- 暂停时动物、树叶、雪花、水面、炉火、粒子、电影颗粒与环境音乐全部同步定格
- 自由观赏时按 W / A / S / D 移动，直接移动鼠标观察，滚轮缩放视角；按住 Alt 临时显示鼠标以点击界面
- 自由观赏时隐藏鼠标指针，右上角实时显示 FPS、主线程耗时、绘制次数、三角形、画质与渲染分辨率
- 拖动：自动巡展中围绕木屋观察，并停止当前季的自动镜头旋转
- 滚轮：调整远近
- 双击画面或点击右上角复位按钮：回到当前场景的初始构图
- 底部四季按钮：手动查看季节，并暂停自动巡展
- 右上角“进入室内 / 回到室外”：切换室外与室内场景，自动巡展继续
- “环境音乐”：控制随季节和场景变化的环境音与背景音乐

## 性能与渲染说明

- WebGL 使用 `powerPreference: "high-performance"`，优先请求独立显卡渲染。
- 画质分为 `high`、`balanced`、`mobile`、`low` 四档，集中管理像素比、阴影、反射、纹理、Bloom、SMAA 与目标帧率；设备默认自动选档，持续慢帧时会逐级降档。
- 巡展、自由预览和室内共用同一帧率调度：电脑最高 60 FPS，手机最高 30 FPS，高刷新率屏幕也不会超过对应上限。
- 暂停且镜头静止时停止持续 RAF；页面进入后台时取消渲染调度并挂起音频，返回后不补跑离开期间的动画。
- 春季室外首帧优先，其他季节与室内按需准备；重复静态小物件在首次渲染前安全合批，并冻结静态矩阵。
- 使用实时水面反射、Bloom、SMAA、ACES 色调映射、雾效与自定义电影调色。反射和阴影按画质档位限频，隐藏的季节粒子不参与更新。
- 音频 PCM 以不超过 32 kHz 的采样率在 Worker 中生成，降低主线程阻塞和内存占用；音频上下文在静音、暂停和后台时挂起，销毁时释放音源。
- 室外树木布置在安全林线之外，相机最小距离限制可避免穿入木屋或树冠。
- 室内相机使用独立旋转范围和距离限制，避免穿墙和进入家具内部。

## 测试说明

`npm test` 使用 `node:test` 覆盖帧调度、画质选择、静态合批、纹理档位、音频状态机、Worker/降级路径和 PCM 合成契约。自动化测试不能替代真实浏览器与手机验收；发布前仍需检查 WebGL 错误、四季切换、暂停恢复、室内外切换、自由镜头、声音快速开关和后台恢复。
